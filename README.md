# Merchant Sales Anomaly Monitor

Streamlit Community Cloud deployment package.

Upload these six files directly to the ROOT of the GitHub repository:

- streamlit_app.py
- requirements.txt
- README.md
- merchant_risk.csv
- daily_sales_prepared.csv
- business_daily_prepared.csv

No raw transaction file is required for the hosted demonstration.

Optional:
To enable Run / Refresh Analysis, also add:
- Transactions.csv
- merchant.csv
- business.csv
- status.csv

Streamlit settings:
- Repository: vsandoram-glitch/merchant-anomaly-detection
- Branch: main
- Main file path: streamlit_app.py
